# Contributing

Issues are welcome here: bugs, model requests, and questions about running
RichEngine on your machine. Include the RichEngine version, the Mac and macOS version,
and the model you were serving.

This repository is a mirror of our development branch, published as a single
commit per release, so pull requests cannot be merged here directly. If you
want to contribute a change, open an issue describing it first. We will work
with you on it, land it in our development branch, and it will appear in the
next release with credit.

[DEVELOPMENT.md](DEVELOPMENT.md) covers building from source, the test suite,
and model packages.
